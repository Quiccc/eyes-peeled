# Security

Please don't report security problems in public issues.

Report them privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Include what you found, how to reproduce it, and what an attacker could do with it.

You'll get an answer within a few days. Please give us a reasonable time to fix the problem before you talk about it publicly.

Out of scope: denial of service by sheer traffic volume, reports from automated scanners without a working example, and missing best-practice headers that have no real impact.
